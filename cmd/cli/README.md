## Installation

### macOS

```bash
brew install maksim-paskal/tap/kubernetes-manager-cli
```

### Linux

Download the CLI binary from the [latest release](https://github.com/maksim-paskal/kubernetes-manager/releases/latest) and install it into `/usr/local/bin`:

```bash
curl -fL https://github.com/maksim-paskal/kubernetes-manager/releases/latest/download/kubernetes-manager-cli-linux-amd64 -o /tmp/kubernetes-manager-cli
chmod +x /tmp/kubernetes-manager-cli
sudo mv /tmp/kubernetes-manager-cli /usr/local/bin/kubernetes-manager
```

On arm64 machines, use `kubernetes-manager-cli-linux-arm64` instead.
